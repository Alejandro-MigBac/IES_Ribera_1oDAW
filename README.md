## 📋 Descripción

Este proyecto es una aplicación web para gestionar tareas diarias, desarrollada para practicar el flujo de trabajo en GitHub y el uso de ramas.

## ✨ Características Principales

* **Gestión de Tareas:** Crear, editar y eliminar tareas en tiempo real.
* **Diseño Responsive:** Adaptado para móviles y escritorio.
* **Persistencia de datos:** Uso de LocalStorage para no perder la información.

## 🛠️ Tecnologías Utilizadas

| Tecnología | Uso |
| :--- | :--- |
| **HTML5 / CSS3** | Estructura y diseño visual. |
| **JavaScript** | Lógica funcional de la aplicación. |
